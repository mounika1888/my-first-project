# 📊 Student Grading Calculator

## About Project
This is a simple web project that calculates student grades based on marks.

## Features
- Enter student name
- Enter roll number
- Enter marks
- Automatically shows grade
- Animated UI design

## Technologies Used
- HTML
- CSS
- JavaScript

## Grade System
- 90–100 → A+
- 80–89 → A
- 70–79 → B
- 60–69 → C
- Below 60 → Fail

## How to Run
1. Download the project
2. Open index.html in browser
3. Enter details and click Calculate
