# Student Grading Calculator

A simple web application that calculates student grades based on marks.

## Features
- Enter student name
- Enter roll number
- Enter marks
- Automatically calculate grade

## Grade Rules
- 90 and above: A+
- 80 to 89: A
- 70 to 79: B
- 60 to 69: C
- Below 60: Fail

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open `index.html` in a web browser.
